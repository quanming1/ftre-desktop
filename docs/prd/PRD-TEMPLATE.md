## 元信息

| 字段 | 值 |
|---|---|
| 阶段 | 对应 TODO 阶段（如 A1） |
| 名称 | 简短描述（如 基础架构 + Channel + EventBus） |
| 状态 | 草稿 / approved / 开发中 / 已验收 |
| 创建日期 | YYYY-MM-DD |
| 定稿日期 | YYYY-MM-DD（approved 时填写） |
| 验收日期 | YYYY-MM-DD（已验收时填写） |
| 关联文档 | docs/TODO.yaml 阶段；AGENTS.md |

## 1. 背景与目标

- **背景**：为什么要做这个阶段（解决什么问题）。
- **目标**：本阶段完成后的可交付状态（一句话）。
- **非目标**：明确不做的事（防止范围蔓延）。

## 2. 需求范围

### 2.1 功能需求

每条需求可勾选、可验收：

- [ ] FR1：描述需求 1（含输入/输出/行为）
- [ ] FR2：描述需求 2

### 2.2 非功能需求

- 性能：...
- 安全：...
- 兼容性：...

## 3. 技术方案

- 模块设计（目录 / 文件 / 职责）
- 关键数据结构
- 依赖选型

## 4. 接口定义

- API / CLI / 协议结构

## 5. 验收标准

每条可执行（命令 / 断言 / 勾选）：

- [ ] AC2：测试全部通过
